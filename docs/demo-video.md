# デモ動画の計画

掲載先は X と GitHub README / BOOTH。テロップは日本語のみで、音は入れない（BGM は後から ffmpeg で載せられるようにする）。
体は棒人間で描く。色は管理画面の骨格表示と同じで、トラッキング中は青、推定中はオレンジにする。本物の位置は半透明の白で重ねる。

## 伝えること

1. Lighthouse 系のトラッカーは、布やものに隠れてベースステーションから見えなくなると飛びやすく、約2秒でロストする。
2. このツールを使うと、隠れてもその場に留まる。
3. 隠れている間も頭の動きから隠れた手や腰の位置を補間し、自分の動きに合わせて追従する。
4. VRChat も、トラッキングが切れたトラッカーをその場で固定する。固定したあとは体を動かしても止まったままで、動きの補間はない。作者の説明では、固定されるのはロスト直前の位置で、ロストまでの約2秒に加速度センサーの推測でずれた場所になる。この点は VRChat でまだ確かめていない。

## VRChat の挙動

VRChat のフィードバック掲示板の報告から調べた（2026-10-27）。公式ドキュメントには解説が見つからなかった。

- 2023年の IK 2.0 以降、布などで隠れてトラッキングが切れたトラッカーは、設定がなくてもその場で固定される。
- 設定の Freeze Tracking on Disconnect（Freeze Trackers on Disconnect とも書かれる）は、電源が切れたときも固定を続ける設定。日本語 UI での表記は見つからなかった。
- 2024年8月のベータでは、ロストしたコントローラーが固定されず、腕が体の横に下りる動作に変わっていた。版によって動作が変わるので、比較の場面には腰のトラッカーを使う。
- VRChat がロストを何で判断しているかは、公開情報にない。Lighthouse は隠れて約0.25秒で `Running_OK` でなくなるが、姿勢が有効の印は2秒のリセットまで立ったままになる。前者で判断していれば固定はほぼ隠れた地点で起き、後者なら約2秒の推測でずれた場所で起きる。

作者が VRChat の鏡の前でトラッカーを動かしながら布をかけ、すぐ止まるか、少し流れてから約2秒で止まるかを確かめる。約2秒で止まったときだけ、main の「ロストまでの2秒は…」のテロップと約13 cm の注記を入れる。

## テロップの書き方

- 1枚は2行まで、1行は22字程度までにする。冒頭の一文くらいの長さなら、X のスマホ表示でも読めることを作者が確かめている。
- 表示時間は1秒に4〜5字を目安に取る（20字なら4〜5秒）。
- テロップと注記はです・ます調で書く。ラベル（補正なし、対応：など）と数値の行は体言のままにする。
- 何がどうなったかを書く。主語のない言い方（置いていかれる）や、「…」で次に引っ張る書き方はしない。
- 数値には何と何を比べたかと、どんな条件で測ったかを添える。
- 「補正なし」「補正あり」はテロップとは別のラベルとして、画面の左上に出し続ける。
- テロップは画面の下、注記は小さな字で右下に出す。

補間の数値は [hand-model.md](hand-model.md) の録画比較（`20261024-170855_body`、体を動かした録画）から取る。この比較は隠した区間の回転を残しているので、回転が届いている場合の値になる。
腕モデルは回転が届いている間だけ手を動かす。Lighthouse の回転は約2秒で止まるので、それより長く隠す場面は IMU の読み取りをオンにして作る。
VRChat の固定との比較で足すかもしれない数値は [phase0.md](phase0.md) の E6-1（動かしながらのトンネル通過）から取る。2秒の IMU 推測で、高さと横方向に最大 12.4 cm と 12.6 cm ずれた。ロストを見つけた時点で固定した場合は、ずれが 3 cm 以下で止まった。
足の場面はその場に留まるところだけを見せる。足と膝の位置を推定する機能はない（腰は身体モデルで補間できる。実験的機能で既定はオフ）。

## 作り方

- 図解・比較の 3D：Python で台本どおりの動きとロスト（実機の形）を合成し、正解付きの `.otsrec` を作る →
  `ots-replay` で実際のフィルタに通す → HTML/SVG で描画 → ヘッドレス Edge（puppeteer-core）で 1 フレームずつ PNG → ffmpeg。
- VRChat の固定の列は補正なしの出力を VRChat で確かめた時点（約0.25秒か約2秒）で止めて描く（VRChat そのものは使わない）。
- 実アプリと VR 主観：再生用の仮想ドライバで SteamVR をエミュレーションし、管理画面と VR View を ffmpeg で画面録画。
  このときだけ `steamvr.vrsettings` を一時的に変え、終わったら戻す。
- テロップは HTML 側で焼き込む。編集とつなぎは ffmpeg。
