# 実験ガイド（合図と動作）

`ots-cli protocol occlude / timed` を実行中に鳴る音と、そのときにやることの対応表。

## 音の種類

| 音 | 聞こえ方 | 意味 |
|---|---|---|
| 低い長めの音 ×N 回 | 「ブー」×N（低い） | **条件 N の始まり**（1 回＝条件 1、2 回＝条件 2…）。この後 `--switch` 秒の準備時間 |
| 短い音 ×3 | 「ピッ・ピッ・ピッ」（約 1 秒間隔） | **カウントダウン**。次の長い音で動作開始 |
| 長い音 | 「ピー」 | **動作を始める**（遮る・姿勢をとる・構える）。`--settle` 秒以内に終える |
| 速い 2 連音 | 「ピピッ」（高め、短い） | **この瞬間から状態をキープ**（遮ったまま・姿勢のまま、または動作の本番） |
| 高い短い音 | 「ピン」（一番高い） | **元に戻す**（外す・立ち上がる・動作をやめる）。`--settle` 秒以内に終える |
| 無音 | — | 休憩（`--rest` 秒）。次の「ピッ・ピッ・ピッ」まで待つ |
| 上がっていく 3 音 | 「ド・ミ・ソ」 | **全部終了**。記録も自動で止まる |

1 試行の流れ: `ピッ・ピッ・ピッ` → `ピー`（始める）→ `ピピッ`（キープ開始）→ `ピン`（戻す）→ 休憩

## E3: ベースステーションを 1 台ずつ遮る

```bash
ots-cli protocol timed --label bs_block --details bs=A,bs=B,bs=C --duration 10 --settle 5 --repeat 2 --switch 15 --record
```

事前準備:
- HMD・コントローラー左右・Tundra 3 台を床や机に置く。どれも 3 台の BS から見える場所に。実験中は触らない。
- 3 台の BS に A・B・C の名前を決めておく。遮るための段ボールかタオルを用意する。
- **BS には触らない**（動くとルームセットアップのやり直しになることがある）。デバイスと BS の間に自分が入らないよう、BS の横か後ろから近づく。

| 経過時間（目安） | 音 | やること |
|---|---|---|
| 0 秒 | 「ブー」×1 | 条件 1（BS A）。**15 秒以内に A の横へ移動**して、段ボールを持って待機 |
| 15 秒 | 「ピッ・ピッ・ピッ」 | 構える |
| 19 秒 | 「ピー」 | **A の正面に段ボールをかざす**（5 秒以内に。BS から 10〜20cm 離して、触れない） |
| 24 秒 | 「ピピッ」 | **かざしたまま 10 秒動かない** |
| 34 秒 | 「ピン」 | **段ボールを下ろし、5 秒以内に BS の横へ下がる**（デバイスとの間に入らない） |
| 39 秒 | 無音 5 秒 | その場で待つ |
| 44 秒 | 「ピッ・ピッ・ピッ」〜 | 2 回目。同じことを繰り返す |
| 約 73 秒 | 「ブー」×2 | 条件 2（BS B）。15 秒以内に B の横へ移動 |
| 約 147 秒 | 「ブー」×3 | 条件 3（BS C）。15 秒以内に C の横へ移動 |
| 約 3.7 分 | 「ド・ミ・ソ」 | 終了 |

## 音声ガイド付きプリセット（E4・E5）

`protocol e4` / `protocol e5` は、ビープに加えて日本語の音声（Microsoft Haruka）で指示を読み上げる。

| タイミング | 読み上げ |
|---|---|
| 最初 | テストの説明と準備（全部聞き終わってから 3 秒後に開始） |
| 条件の始まり | 「ブー」×N のあとに、その条件で何をするかの説明 |
| 各回の最初 | 「1 回目」「2 回目」… → 「ピッ・ピッ・ピッ」 |
| 「ピー」の直後 | 動作の指示（例: 「前屈して」「構えて」） |
| 「ピピッ」の直後 | キープの指示（例: 「そのまま」「ぶつけて」） |
| 「ピン」の直後 | 戻す指示（例: 「起きて」「止めて」） |
| 最後 | 「テストは終了です。お疲れさまでした。」 |

事前に `ots-cli voice-test` で声が聞こえるか確認できる（ヘッドセットのスピーカーから聞く場合は、Windows の既定の出力先をヘッドセットにしておく）。

## E5: 衝撃と速い動き

```bash
ots-cli protocol e5 --record
```

事前準備: コントローラーを両手に持つ。足の Tundra を装着する。周りに物がないことを確認する。

| 音 | 声 | 条件 1 `clap` | 条件 2 `swing` | 条件 3 `stomp` |
|---|---|---|---|---|
| 「ピッ・ピッ・ピッ」 | （N 回目） | 普通に立つ | 普通に立つ | 普通に立つ |
| 「ピー」（1.5 秒） | 「構えて」 | リング同士を近づける | 腕を後ろに引く | 足を少し上げる準備 |
| 「ピピッ」（3 秒間） | 「ぶつけて」「振って」「踏んで」 | **リング同士を軽く 2〜3 回ぶつける** | **ボールを投げるように素早く 2〜3 回振る** | **強めに足踏みを 3〜4 回** |
| 「ピン」（1.5 秒） | 「止めて」 | 手を止めて静止 | 腕を下ろして静止 | 止まって静止 |
| 無音 5 秒 | — | 静止して待つ | 静止して待つ | 静止して待つ |

1 条件につき 3 回。全体で約 3 分。一部の条件だけやり直すときは `--only stomp` のように指定する（例: `ots-cli protocol e5 --only stomp --record`）。

## E4: 体の陰に入る姿勢

```bash
ots-cli protocol e4 --record
```

事前準備: HMD・コントローラー・Tundra 3 台（腰 1A2B3C05・左足 1A2B3C02・右足 1A2B3C03）を普段どおり装着し、プレイエリアの中央に立つ。

| 音 | 声 | 条件 1 `bend` | 条件 2 `crouch` | 条件 3 `sit` | 条件 4 `lie` |
|---|---|---|---|---|---|
| 「ピッ・ピッ・ピッ」 | （N 回目） | 中央に立つ | 中央に立つ | 中央に立つ | 中央に立つ |
| 「ピー」 | 「前屈して」「しゃがんで」「座って」「寝て」 | **深く前屈する**（4 秒） | **しゃがむ**（4 秒） | **床にあぐらで座る**（5 秒） | **床に横向きに寝る**（7 秒） |
| 「ピピッ」（3 秒間） | 「そのまま」 | 前屈のまま静止 | しゃがんだまま静止 | 座ったまま静止 | 寝たまま静止 |
| 「ピン」 | 「起きて」「立って」 | 体を起こす（4 秒） | 立ち上がる（4 秒） | 立ち上がる（5 秒） | 起き上がって立つ（7 秒） |
| 無音 5 秒 | — | 立って静止 | 立って静止 | 立って静止 | 立って静止 |

1 条件につき 3 回。全体で約 6 分。回数を減らしたいときは `--repeat 2`。

## 途中で止めるとき

実行中のターミナルで Ctrl+C を押してから:

```bash
ots-cli stop
```
